# Ra & Apep

A cinematic, scroll-driven telling of the ancient Egyptian myth of the sun god's
nightly voyage through the underworld and his battle with the chaos serpent Apep.
The page *is* the night: it opens at sunset, descends through the twelve hours of
the Duat, stages the battle of the seventh hour, and ends at sunrise.

- **English** — <https://o1tean.github.io/ra-and-apep/>
- **Română** — <https://o1tean.github.io/ra-and-apep/ro/>

## Running it

There is no build step and there are no dependencies. Open `index.html` in a
browser, or serve the folder:

```bash
python3 -m http.server 4517
```

Two query parameters help when testing: `?still` snaps scroll animation to the
scrollbar instead of easing toward it, and `?selfcheck` asserts the scroll-progress
maths in the console.

## How it is built

| File | Role |
| --- | --- |
| `index.html`, `ro/index.html` | The two language editions. Everything else is shared. |
| `tokens.css` | Colour, type, spacing and motion tokens. |
| `styles.css` | The world. Base CSS is a complete static article; `html.fx` adds the film. |
| `main.js` | ~100 lines, no dependencies. Writes one number per scene, `--p` from 0 to 1; CSS does the choreography. |
| `tools/build-images.py` | Turns `assets/img/raw/` into the shipped WebP files. Safe to re-run. |

Scrolling is never hijacked — pinned scenes use `position: sticky`. The page
honours `prefers-reduced-motion` and offers an on-page motion switch; with motion
off, or with JavaScript disabled, it remains a complete illustrated article.

Design documents live in `PRODUCT.md`, `DESIGN.md` and `.design/ra-and-apep/`.

## About the images

Every illustration was generated by AI for this project — the Duat and battle
scenes and cut-out figures by OpenAI's image model, the other painted scenes by
Google's Gemini. They are interpretations, not artefacts. The refreshed scenes
ship as responsive WebP images at 960 px and their native 1672 px, without
upscaling. The hieroglyphs on the page are real ones, set as text.
Exact prompts are in `assets/img/prompts/`, provenance in `assets/img/PROVENANCE.md`.

## Accuracy

Claims are drawn from the Amduat, the Book of Gates, Book of the Dead spell 17 and
Papyrus Bremner-Rhind, and most were checked against reference sources. A few
details — the 450-cubit sandbank, Serqet's fetters, the serpent "Life of the Gods",
the daily rite at Karnak and the green ink — are written from the Hornung and
Faulkner editions and have not been verified against them line by line.
